# AIエージェントに通貨APIをMCPで接続する方法

## 結論

MCPプロトコルは、AIエージェントが外部の通貨APIに安全に接続できるためのオープンソース標準であり、APIキーの共有を必要とせず、サーバーが自身のリソースを制御できる点でセキュリティが確保されています。また、ECBなどの中央銀行が提供する公式為替レートは、APIキーを使わずにもPythonやGitHubなどのツールを通じて取得可能で、AIエージェントが正確なデータに基づいて行動するための基盤となっています。

## テーマ概要

MCP（Model Context Protocol）は、AIアーキテクチャが外部データソースやツールに安全に接続できるようにするオープンソースプロトコルであり、Anthropicによって開発されました。このプロトコルは、AIエージェントが外部のデータやツールにアクセスするための統一された基準を提供し、セキュリティを確保します。特に、通貨APIをAIエージェントに接続する方法として注目されています。これは、実時間の通貨レートや経済データを取得し、AIエージェントが正確な情報を基に判断や行動を取るための必要条件です。また、MCPはAPIキーの共有を必要とせず、サーバーが自身のリソースを制御できるため、セキュリティと信頼性が確保されています。このような背景から、通貨APIとAIエージェントの接続方法が注目されており、特に金融分野での応用が期待されています。

## 共通して確認できる点

複数の記事から共通して確認できた事実として、MCP（Model Context Protocol）はAIアーキテクチャが外部データソースやツールに安全に接続できるオープンソースプロトコルとして位置付けられている。このプロトコルは、Anthropicによって開発され、ClaudeなどのAIアーキテクチャが外部データやツールにアクセスするためのクライアントサーバー型の標準的なインターフェースを提供している。MCPを活用することで、AIエージェントはリアルタイムデータにアクセスし、古い情報やhallucinationを避けることができる。また、MCPサーバーは、MCP.so、Apify MCPサーバー、またはAwesome MCP Serversなどのプラットフォームで利用可能であり、それらはそれぞれ異なるツールや機能を提供している。一方、通貨APIとの連携においては、MCPを通じて、例えばUSDからUAHへの為替レートを取得するAPIが利用可能であり、そのMCPサーバーはGlamaによってホストされている。さらに、ECB（欧州中央銀行）などの中央銀行が提供する公式為替レートは、APIキーを必要とせず、PythonやGitHubなどのツールを通じてアクセス可能であり、これらのレートは会計や法的用途に利用される。また、MCPプロトコルは、サーバーが自身のリソースを制御し、LLMプロバイダーにAPIキーを共有する必要がないというセキュリティ特性を持つ。これらの要素は、AIエージェントが通貨APIと連携する際の重要な基盤を形成している。

## 深掘り調査で得られた知見

MCP（Model Context Protocol）は、AIエージェントが外部データソースやツールに安全に接続できるようにするオープンソースプロトコルで、Anthropicによって開発されました。このプロトコルを使用することで、AIエージェントはAPIキーを共有せずに、必要なデータにアクセスできます。例えば、USDからUAHへの為替レートを取得するためのCurrency Exchange APIをMCP経由でAIエージェントに接続する方法が示されています。その際、MCPサーバーはGlama上でホストされており、URLは。このサーバーを使用するには、Claude Desktopの設定ファイル（claude_desktop_config.json）を編集し、MCPサーバーの設定ブロックを追加する必要があります。

一方、為替レートの取得に関しては、ECB（欧州中央銀行）などの中央銀行が提供する公式なデータをAPIキーを使わずにも利用できる方法が紹介されています。例えば、Apifyの「Central Bank Exchange Rates」アクターは、ECB、NBP（ポーランド銀行）、CNB（チェコ共和国銀行）、カナダ銀行、ノルウェー銀行などのデータを取得できます。また、GitHubの「central-bank-exchange-rates」リポジトリでは、122の中央銀行と4の税関機関の為替レートが毎日更新され、JSONやCSV形式で提供されています。これらのデータはGitHubから直接取得可能で、CORSを有効にしており、コミット後5分以内に更新されます。

さらに、SML FX ConvertというAPIは、ECBの参考為替レート（EXRデータセット）を用いて為替変換を提供しており、AIエージェントが複数通貨間の価格設定、レポート作成、予算管理を行うのに適しています。このAPIはサブスクリプションやAPIキーを必要とせず、1回あたりの変換には$0.001 USDCの料金が発生します。また、ECBデータポータルでは、EXRデータセットが毎日午後4時に更新され、FXデータセットが夜間に更新されることが明記されています。これらの情報は、AIエージェントが正確な為替レートを取得し、信頼性の高いデータに基づいて行動するための重要な要素です。
