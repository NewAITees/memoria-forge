# Spinifex 1.19.0 が1.0.0から5か月で19回リリースし、AWSサポートを3から11に拡大

## 結論

Spinifex 1.19.0 は、1.0.0から5か月間かけて19回のリリースを経て、AWSのサポート対象サービスを3から11に大幅拡張し、生産環境でのテストコードを実装したバージョンである。この更新により、プラットフォームは単なる機能拡張にとどまらず、実際の生産環境での運用を可能にする技術的実証を達成した。

## テーマ概要

Spinifex 1.19.0 は、同名のプラットフォームが 1.0.0 から 5 か月間かけて 19 回のリリースを経て、最終的にリリースされたバージョンである。このバージョンでは、初期の 3 つの AWS サービス（EC2、EBS、S3）から、ALB/NLB、EKS、ACM、ECR、ECS、RDS など合計 11 の AWS サービスへのサポートが拡張され、生産環境での実証コードも実装された。この更新により、Spinifex は単なる機能拡張だけでなく、実際に生産環境でテストされたコードを提供するようになった。また、インターネット接続がない環境でも利用可能な内部リポジトリからのイメージプル機能や、ECS と ECR の統合など、多様な用途に対応する設計が特徴である。このような大幅な進化が、このバージョンが注目されている理由となっている。

## 共通して確認できる点

Spinifex 1.19.0 は、2026年10月にリリースされたバージョンであり、1.0.0から5か月間の開発期間を経て、19回のリリースを経て完成した。1.0.0ではEC2、EBS、S3の3つのAWSサービスのみをサポートしていたが、1.19.0ではALB/NLB、EKS、ACM、ECR、ECS、RDSなど、合計11のAWSサービスをサポートするように拡張された。このバージョンでは、生産環境でのテストコードを実装し、生産準備の主張を実証した。また、インターネット接続がない環境での利用を想定し、内部リポジトリからイメージをプルする機能も導入されている。

## 深掘り調査で得られた知見

Spinifex 1.19.0 は、リリース後 5 か月間、19 回のリリースを経て公開されました。この期間を通して、プラットフォームは初期の 3 つの AWS サービス（EC2、EBS、S3）から、ALB/NLB、EKS、ACM、ECR、ECS、RDS などの 11 のサービスにまで拡張されました。特に、ALB は HAProxy を使用し、NLB は nginx stream を採用することで、L7 と L4 のサポートを実現し、HTTPS リスナー、ヘルスチェック、リスナー規則を備えています。EKS では K3s コントロールプレーンを採用し、IRSA や OIDC プロバイダーを備えた IAM 認証が実装されています。ECR は OCI リポジトリとして、docker、crane、skopeo をサポートし、ライフサイクルポリシー、不変タグを備えています。RDS は PostgreSQL 18.1 と MariaDB をサポートし、プライベートエンドポイントで VPC 内で運用されるようになっています。また、インターネット接続がない環境での利用を想定し、内部リポジトリからイメージをプルする機能も備えています。ECS では、各タスクが独自の ENI と VPC IP を持つことで、ELBv2 ターゲットグループに登録され、コンテナがロードバランサーの裏に配置されます。EKS では、etcd サーバーが可用性ゾーンに分散され、AZ の喪失でもクラスターが動作し続けるように設計されています。Spinifex 1.19.0 では、実際の生産環境でのテストコードを実現し、生産準備の主張を実証しました。
