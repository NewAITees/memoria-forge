# Tailwind CSS統合後、ShopifyがReact Nativeから移行

## 結論

Tailwind CSSがShopifyに統合され、その1日後にShopifyがReact NativeからSwiftとKotlinへの移行を発表したことは、AI技術の進展が既存の技術スタックや開発モデルに深刻な影響をもたらしていることを明確に示している。この出来事は、技術分野におけるAIの影響が急速に広がり、企業の技術戦略に大きな変化をもたらしていることを示している。

## テーマ概要

Tailwind CSSがShopifyに統合されたことと、その1日後にShopifyがReact NativeからSwiftとKotlinへの移行を発表した出来事は、技術コミュニティにおいて大きな注目を集めている。この出来事は、AI技術の進展が既存の開発フレームワークやプラットフォームに与える影響を象徴している。Tailwind CSSは、利用者数が週に1億1000万回を超え、ChatGPT、X、Cloudflare、Reddit、Shopifyなど大手企業でも採用されている人気フレームワークであるが、AIによるドキュメンテーションの需要減少や商用製品の収益低下が原因で、Tailwind LabsがShopifyに買収されることになった。一方、ShopifyはReact Nativeの利用を縮小し、SwiftとKotlinへの移行を進める決定を発表した。これは、コードジェネレーターやAIツールの進化により、開発効率が向上したためとされている。この出来事は、技術分野におけるAIの影響が急速に広がり、既存の技術スタックや開発モデルに大きな変化をもたらしていることを示している。

## 共通して確認できる点

Tailwind CSSは2026年9月9日にShopifyに統合され、その開発は今後Shopifyの傘下で進められることが明らかになった。この決定は、Tailwind CSSの収益がAI技術の台頭によって大幅に減少したことを背景にしている。特に、LLM（大規模言語モデル）によるドキュメンテーションの自動生成により、Tailwindの有料製品へのアクセスが減少し、収益モデルが危機にさらされていた。Tailwind CSSは依然としてMITライセンスで無料で利用可能であり、コアフレームワークやCLIはオープンソースとして維持されるが、有料製品であるTailwind Plusやui.shは新規ユーザーの登録を停止している。一方で、Shopifyは同日、React NativeをSwiftとKotlinへの移行を発表し、コードジェネレーターエージェントの導入により開発効率を高める方針を示した。この移行により、Shopifyのアプリは今後、ネイティブ開発が主流となる見込みである。

## 深掘り調査で得られた知見

Tailwind CSSの開発元であるTailwind LabsがShopifyに買収されたこと、およびその1日後にShopifyがReact NativeからSwiftとKotlinへの移行を発表した事実は、技術界に大きな波紋を広げた。この買収は、Tailwind CSSの収益がAI技術の台頭により大幅に減少した背景にある。特に、LLM（大規模言語モデル）がドキュメンテーションの需要を削減し、Tailwind Plusやui.shなどの有料製品の新規契約が減少したことが要因となった。Tailwind CSSはMITライセンスのまま、無料で利用可能で、コアフレームワークやCLIはオープンソースとして維持されるが、有料製品は新規ユーザーの登録を停止している。

一方、ShopifyはReact Nativeの使用を終了し、すべてのアプリをSwiftとKotlinに移行することを決定した。この決定は、コードジェネレーターやAIツールの導入により、React Nativeでの開発がもはや効率的でなくなったという理由からである。特に、ネイティブ開発により、Shopifyアプリの再構築が12週間で完了し、Androidでの起動が50%早くなったとされている。この変更は、ShopifyがReact Nativeへの信頼を失ったことを示しており、今後はネイティブ開発に注力する方針である。

また、React Native開発者を採用する際には、MVP（Minimum Viable Product）の開発に特化したチームやフリーランス開発者を採用することが推奨されている。MVPでは、過度な設計や機能追加を避けて、迅速にテスト可能な製品を構築することが重要であり、履歴書や経験年数よりも実績やスキルが重視される。さらに、React Nativeアプリの開発コストに関する詳細なブレイクダウンも行われており、スタートアップはMVPを優先的に構築すべきである。AI技術の進展により、開発プロセスやフレームワーク選定にも新たな変化が生じている。
