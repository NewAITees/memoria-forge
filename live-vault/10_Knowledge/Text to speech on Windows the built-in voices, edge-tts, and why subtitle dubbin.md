# Windows 11のテキスト読み上げとElevenLabsのDubbing v2の違い

## 結論

Windows 11 におけるテキスト読み上げ機能では、SAPI レジストリ ヘイブと OneCore レジストリ ヘイブに分かれた 2 世代の音声が存在し、System.Speech は SAPI ヘイブの音声のみを認識する。Edge-TTS は Microsoft Edge のオンライン TTS サービスを Python から利用可能で、MP3 形式で出力し、音声の速度やボリューム、ピッチを調整できるが、--write-media、--write-subtitles、--list-voices オプションは edge-playback と併用できない。一方、ElevenLabs の Dubbing v2 は、多言語対応と音声のタイミング・感情を保持する技術により、動画のローカリゼーションをより自然で表現豊かなものにすることを目指しており、クリエイター、マーケティングチーム、メディア機関向けに提供されている。

## テーマ概要

Windows におけるテキスト読み上げ機能には、ビルトインの音声、Edge-TTS といったツールが利用可能である。ビルトイン音声は SAPI レジストリ ヘイブに保存され、System.Speech はその音声のみを認識する一方、Edge-TTS は Microsoft Edge のオンライン TTS サービスを Python から利用可能で、MP3 形式で出力し、音声の速度やボリューム、ピッチを調整できる。一方で、サブタイトルの音声化には、音声が長いことからスクリプトと合わない可能性があり、音声生成の際には音声の長さに合わせてビジュアルをカットする方が効率的である。このような背景から、テキスト読み上げとサブタイトルの音声化が注目されている。また、ElevenLabs が発表した Dubbing v2 は、多言語対応と音声のタイミング・感情を保持する技術により、動画のローカリゼーションをより自然で表現豊かなものにすることを目指しており、今注目されている。

## 共通して確認できる点

Windows 11 には SAPI レジストリ ヘイブと OneCore レジストリ ヘイブに分かれた 2 世代の音声が存在し、System.Speech は SAPI レジストリ ヘイブの音声のみを認識する。Edge-TTS は Microsoft Edge のオンライン TTS サービスを Python から利用可能で、pip install でインストールできる。Edge-TTS は MP3 形式で出力し、音声の速度、ボリューム、ピッチを調整可能である。また、Edge-TTS は --write-media、--write-subtitles、--list-voices オプションは edge-playback と併用できない。SSML のカスタマイズは制限されており、Microsoft Edge 自身が生成できる SSML に限られている。音声を生成する際、音声の長さに合わせてビジュアルをカットする方が効率的である。

一方、ElevenLabs は Dubbing v2 をリリースし、1 人以上の話者、背景音の管理、地域ごとのアクセントの調整など、複雑な音声シーンに対応できる機能を追加した。この更新により、音声のタイミングや感情、発話のテンポを保持しながら、90 言語以上へのローカライズが可能になった。ElevenLabs は、この技術を ElevenCreative と ElevenProductions に統合し、クリエイター、マーケティングチーム、メディア機関向けに提供している。

## 記事ごとの差分・視点の違い

記事1は、Windowsの組み込み音声とEdge-TTSの比較に焦点を当て、サブタイトルの音声化がうまくいかない理由を説明しています。特に、音声の長さとサブタイトルのタイミングの違いが原因であると指摘しています。また、Edge-TTSの使い方やインストール方法、音声のカスタマイズオプションについても述べています。一方、記事2はEdge-TTSのPythonでの利用方法と、その制限について詳しく説明しており、SSMLのカスタマイズが制限されている点を強調しています。記事3と記事4はElevenLabsのDubbing v2について触れ、方言や背景音の制御機能を強調しています。記事5は、Dubbing v2が90以上の言語をサポートし、翻訳を音声に合わせて調整する仕組みについて述べており、クリエイター向けの価値を強調しています。各記事は、それぞれの技術や用途に応じた視点で情報を提供しており、読者に異なる情報を提供しています。

## 深掘り調査で得られた知見

Windows 11 におけるテキスト読み上げ機能には、SAPI レジストリ ヘイブと OneCore レジストリ ヘイブに分かれた 2 世代の音声が存在する。System.Speech は SAPI ヘイブの音声のみを認識し、OneCore ヘイブの音声は選択できない。これにより、インストールした音声がリストに表示されない場合がある。Edge-TTS は Microsoft Edge のオンライン TTS サービスを Python から利用可能で、pip install でインストールできる。Edge-TTS は MP3 形式で出力し、音声の速度、ボリューム、ピッチを調整可能である。ただし、--write-media、--write-subtitles、--list-voices オプションは edge-playback と併用できない。また、SSML のカスタマイズは制限されており、Microsoft Edge 自身が生成できる SSML に限られる。サブタイトルの音声化では、音声が長いことから、スクリプトの長さと合わない可能性があり、音声を生成する際は、音声の長さに合わせてビジュアルをカットする方が効率的である。  

ElevenLabs は Dubbing v2 をリリースし、1 人以上の話者や背景音声を含む複雑な音声シーンに対応する機能を追加した。この更新により、地域ごとのアクセントや、背景音声の管理が可能となり、より自然で表現力のあるローカリゼーションが実現できる。また、Dubbing v2 は、元の音声のタイミングや感情を保持しながら、複数の言語に翻訳することができ、これにより、翻訳後の音声が自然に聞こえるように調整される。ElevenLabs は、この機能を、クリエイター、マーケッター、放送局など、大規模なローカリゼーションを求めるユーザー向けに提供しており、ElevenCreative と ElevenProductions で利用可能である。
