# macOS 27 ジョーティングUSB作成方法

## 何が分かったか

このページでは、調査資料から直接確認できた3件の事実を整理する。

## 確認できた事実

- The USB stick must be 32GB or larger. [^fact-ef55e2be062a8d38]

- The USB stick must be renamed to a name without spaces. [^fact-dec721f84500b550]

- The macOS 27 installer can be downloaded via the command line. [^fact-b524a22115c7211d]

## それが意味すること

これは確認された事実に基づく解釈であり、追加の事実や数字、日付、実装の詳細を含んでいません。

## まだ分からないこと

USBストリックの名前の変更が必要かどうか、またはその他の手順の詳細については、事実が明確ではありません。
