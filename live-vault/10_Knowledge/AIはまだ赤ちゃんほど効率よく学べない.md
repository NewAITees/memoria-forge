AIの専門用語を分かりやすく解説しました。以下は、AIに関する基本的な用語とその説明の一覧です。今後のAI活用のために、ぜひ参考にしてください！

### AI用語集（基本から最新トレンドまで）

| 用語 | 説明 |
|------|------|
| **AI（人工知能）** | 人間の知能（学習、推論、認識、判断など）をコンピュータ上で模倣・再現する技術の総称。 |
| **ANI（特化型AI）** | 特定のタスク（将棋、画像認識、会話など）に優れたAI。 |
| **AGI（汎用人工知能）** | 人間のようにあらゆる知的作業をこなせるAI。まだ実現されていない。 |
| **ASI（超知能）** | 人間を遥かに超える知能を持つAIの概念。 |
| **機械学習** | 大量のデータから「ルール」や「パターン」を自動的に学習させる手法。 |
| **ディープラーニング** | 神経ネットワークを多層に重ねた機械学習の一種。 |
| **ニューラルネットワーク** | 人間の脳の神経細胞（ニューロン）を模したAIの基本構造。 |
| **自然言語処理（NLP）** | 人間の言葉（自然言語）を理解・生成させる技術。 |
| **コンピュータビジョン** | 画像や映像を「見て」理解する技術。 |
| **シンギュラリティ** | AIが人間の知能を超越し、AI自身がより賢いAIを作り出す転換点。 |
| **ターミナルテスト（Turing Test）** | 人間が画面越しに会話を行い、相手が人間か機械か見分けがつかなければ「合格」とされるテスト。 |
| **生成AI** | テキスト、画像、音声、動画など新しいオリジナルデータを創造できるAI。 |
| **LLM（大規模言語モデル）** | WEB上の膨大なテキストを学習し、言葉の意味や文脈を理解するAIモデル。 |
| **マルチモーダルAI** | テキスト、画像、音声、動画など複数の種類のデータを同時に理解・処理できるAI。 |
| **ファクトチェック** | AIが出力した情報が事実かどうかを確認する作業。 |
| **トークン** | AIが処理する最小単位のデータ（単語や文字の一部）。 |
| **コンテキストウィンドウ** | AIが一度の会話で読み込める情報量の上限。トークン数で測定されます。 |
| **ランダム性パラメータ（temperature）** | AIの出力の「創造性・ランダム性」を制御する設定値。 |
| **RLHF（人間フィードバックを用いた強化学習）** | AIの出力を人間が「良い/悪い」と評価し、その評価を元にAIを改善していく学習手法。 |
| **ファインチューニング** | 既存のAIモデルを特定のデータで再学習させ、カスタマイズする技術。 |
| **API（アプリケーションプログラミングインターフェース）** | AIを他のアプリやシステムと連携するための仕組み。 |
| **オンプレミスAI** | インターネット上のサーバーで動くAI（クラウドベース）。 |
| **オンデバイスAI** | スマートフォンやカメラなど、端末内で動くAI。 |
| **AIによる自動化** | AIを使って業務を自動化する技術。 |
| **AIツール** | プログラミング不要でAIを活用できるツール。 |
| **AIによる予測分析** | AIを使ったデータ分析・予測技術。 |
| **AIによる文章生成** | AIを使って文章を自動生成する技術。 |
| **AIによる画像生成** | AIがテキストや画像をもとに画像を生成する技術。 |
| **AIによる動画生成** | AIがテキストや画像をもとに動画を作成する技術。 |
| **AIによる音声合成** | AIを使って顔や声を合成する技術。 |
| **AIによる画像編集** | AIが画像を編集・生成する技術。 |
| **AIによる音声認識** | AIが音声を文字に変換する技術。 |
| **AIによる音声合成** | AIが文字を音声に変換する技術。 |
| **AIによる音声翻訳** | AIが音声を別の言語に翻訳する技術。 |
