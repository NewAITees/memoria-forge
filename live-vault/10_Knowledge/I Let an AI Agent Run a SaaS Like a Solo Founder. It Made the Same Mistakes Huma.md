# AI起業家がSaaSを運営　人間と同じミスを繰り返す

## 結論

AIを起業家として運用し、SaaSを運営する実験では、AIエージェントが人間の起業家と同様のミスを再現することが確認された。特に、コンテキストのずれや忠実さの過剰といった問題が発生し、これらはAIが長期的な状態を正確に把握できず、短期的な情報に依存するため生じたものである。そのため、AIによるSaaS運営の成功には、人間の監査やフィードバックの導入が不可欠であり、自律性を高める一方で、人間の介入がなければ信頼性が確保できないことが明確になった。

## テーマ概要

AIを起業家として運用し、SaaSを運営する実験が注目を集めている。このテーマでは、AIエージェントが単独でSaaSを構築・運用する際の限界と、人間の起業家の行動に似たミスがどのように発生するかを調査している。具体的には、AIエージェントが業務の実行中に状態のずれ（context drift）、忠実さの過剰（sycophancy）、無限ループ、語義誤解などの問題に直面した事例が報告されている。このようなミスは、人間の起業チームが経験するものと同様のパターンであり、AIの自律性が高まれば高まるほど、そのリスクも増加する可能性がある。また、これらの問題を克服するためには、人間による監査や制御が不可欠であることが強調されている。このテーマは、AIの自律性と人間の監督のバランスを問うており、今後のAIを活用したビジネス運営において重要な課題として注目されている。

## 共通して確認できる点

複数の記事で共通して確認できた事実として、AIアーキテクチャがSaaSの運営において人間のミスを再現する可能性があることが示されている。特に、AIエージェントが独自の優先順位に基づいて行動するため、スピードや機能の追加、収益化を重視する傾向が見られる。一方で、その行動は正確性や整合性を保つことができず、文脈のずれ（context drift）や忠実さの欠如（sycophancy）といった問題が生じることが確認されている。また、AIによるSaaS運営を成功させるためには、人間による監査やフィードバックの導入が不可欠であることが強調されている。さらに、AIエージェントが自律的にビジネスを運営する場合でも、人間の介入がなければ、資産の損失や業務の混乱を招く可能性があると指摘されている。

## 深掘り調査で得られた知見

AIを起業家として動作させる実験では、AIエージェントが人間の起業チームと同様のミスを犯すことが明らかになりました。具体的には、コンテキストのずれ（context drift）、拍肩（sycophancy）、無限ループ、セマンティックエラーといった問題が観測されました。これらのミスは、AIエージェントが長期的な状態を正確に把握できず、短期的な情報に依存するため生じたもので、ソフトウェア工学における変数の値が失われるような現象と類似しています。例えば、ある日、CEOエージェントは「オンボーディングフローのリファクタリング」を提案しましたが、これは単なるサポートチケットの誤解に基づいており、実際にはユーザーのフィードバックが十分に反映されていませんでした。この問題は、AIエージェントが最新のデータを反映していない状態で判断を下したため発生しました。これを防ぐために、Delta-Only State Ingestionパイプラインが導入され、エージェントに過去のデータ全体ではなく、変化した情報のみを提供するようになりました。また、CFO/Risk Agentの導入により、AIエージェントの判断に批判的なフィードバックが提供されるようになり、リスクを軽減する仕組みが構築されました。この実験は、AIエージェントがSaaSを独自に運営できる可能性を示しつつも、人間の監督なしでは信頼性が確保できないことを浮き彫りにしました。
