# ゼロコピーとマルチプロトコルストレージのデータパイプライン設計

## 結論

ゼロコピー技術は、データを物理的に複製せず元の場所から直接アクセス可能にする手法であり、ETLプロセスを不要にすることでコスト削減やリアルタイム処理の実現が可能である。Salesforceでは2025年6月にData Cloudを刷新し、ゼロコピー基盤を導入することでデータを複製せずにセキュアかつリアルタイムなアクセスを実現し、プライバシー規制への準拠やスケーラブルなパーソナライズが可能となった。しかし、ゼロコピーはすべてのケースで最適な選択肢とは限らず、プライベート接続環境や大量データの複雑な変換処理が必要なケースでは従来のバッチコピーが依然として合理的な選択肢である。

## テーマ概要

ゼロコピー（Zero-Copy）は、データを物理的に複製することなく、元の場所から直接アクセス可能な技術で、リアルタイムなデータ活用やコスト削減、ガバナンスの向上を実現します。この技術は、ETL（抽出・変換・読み込み）プロセスを不要にすることで、従来のバッチ処理や同期ジョブに代わる選択肢として注目されています。特に、SAP BDC ConnectやSalesforce Data 360などのプラットフォームがゼロコピーを採用し、多プラットフォームでのデータ連携を可能にしています。また、ゼロコピーはマルチプロトコルストレージ技術としても実装され、SMB、NFS、S3 APIなど複数のプロトコルで同じデータにアクセス可能です。2025年6月、SalesforceはData Cloudを刷新し、ゼロコピー基盤を導入することで、データの複製なしにセキュアかつリアルタイムなアクセスを実現しました。これにより、プライバシー規制への準拠やスケーラブルなパーソナライズが可能となり、データ活用の新たなモデルとして注目されています。

## 共通して確認できる点

ゼロコピー技術は、データを物理的に複製せず元の場所から直接アクセス可能にする手法であり、ETLプロセスを不要にすることでコスト削減やリアルタイム処理の実現が可能となっています。この技術は、SMB、NFS、S3 APIなどの複数プロトコルをサポートするマルチプロトコルストレージ技術として実装されており、処理時間の短縮を実現しています。Salesforceは、Data Cloudを2025年6月に大幅に進化させ、ゼロコピー基盤を導入することで、データを複製せずにセキュアかつリアルタイムでアクセスできる仕組みを提供しています。これにより、プライバシー規制への準拠やスケーラブルなパーソナライズが可能となりました。また、Salesforce Data 360は、2025年10月21日にブランド変更され、ゼロコピーデータ統合を提供し、CRM内外のあらゆるデータを連携する中核的な役割を担っています。ゼロコピーは、従来の同期ジョブやバッチ処理に代わる選択肢として検討されており、特に大量データや複雑な変換処理が必要な場合に従来のバッチコピーが依然として合理的な選択肢であることも確認されています。

## 深掘り調査で得られた知見

ゼロコピー技術は、データを物理的に複製せず、元の場所から直接アクセス可能にする手法であり、ETLプロセスを不要にすることでコスト削減、リアルタイム処理、ガバナンスの向上が可能である。この技術は、SAP BDC Connectを中核に据えたゼロコピー構成により、多プラットフォームでの運用を可能にする実用的な選択肢として検討されている。Salesforceでは、2025年6月にData Cloudを大きく前進させ、ゼロコピー基盤を導入した。2025年10月21日には、Data 360がゼロコピーデータ統合を提供し、リアルタイムなデータ活用を可能にした。ゼロコピーは、S3アクセスポイントの読み取りが即時で、イベントからデータ書き込みまでの処理時間が数秒と短縮されるなど、従来の同期ジョブ間隔よりも大幅な改善を実現している。ただし、ゼロコピーはすべてのケースで最適な選択肢であるとは限らず、プライベート接続環境や大量データの複雑な変換処理が必要なケースでは、従来のバッチコピーが依然として合理的な選択肢である。また、ゼロコピーは、複数プロトコル（例：SMB、NFS、S3 API）で同じデータにアクセス可能なマルチプロトコルストレージ技術として実装されている。

## 不確実な点・追加確認が必要な点

ゼロコピー技術とマルチプロトコルストレージの関連性について、各記事の内容を比較すると、いくつかの点で食い違いや不明点が確認される。まず、ゼロコピーの定義や実装方法については、記事1や記事4が明確に説明しており、データを物理的に複製せず直接アクセス可能な技術であることが一致している。しかし、記事5ではゼロコピーがマルチプロトコルストレージ技術として実装されていると記述されており、他の記事では明示されていないため、その関連性について断定することはできない。

また、Salesforceがゼロコピー技術を導入したタイミングについても、記事2と記事4が2025年10月21日に公開された情報をもとに、Data 360がゼロコピーデータ統合を提供していると記載している。一方で、記事4では2025年6月にData Cloudがゼロコピー基盤を導入したと述べており、この時系列の整合性について確認が必要である。さらに、記事5ではPOC環境でのゼロコピー連携が実現され、処理時間が数秒で達成されていると記述されているが、具体的な実装環境やスケールアップの可能性については詳細が不足している。
