# Shopifyのカテゴリフィルタが機能しない問題の実態

## 結論

Shopifyのagent-commerceカテゴリフィルタは、2026年9月のテストにおいて、190店舗を対象に検証された結果、意図通りに機能していないことが確認されました。カテゴリフィルタを適用しても結果がフィルタリングされず、価格フィルタのみが正しく動作しており、AIショッピングエージェントが正確な商品情報を取得する際の重大な制限となっています。この問題は、Shopifyのドキュメンテーションと実際のAPI動作の乖離を示しており、開発者やストアオーナーにとって重要な課題となっています。

## テーマ概要

Shopifyのagent-commerceカテゴリフィルタが正しく機能していないという問題が、2026年9月に発覚した。この問題は、ShopifyのUCP（Universal Commerce Protocol）エンドポイントにおけるカテゴリフィルタの実装ミスが原因で、190のストアを対象にテストが行われた結果明らかになった。テストでは、カテゴリフィルタを適用しても結果がフィルタリングされず、価格フィルタのみが正しく動作することが確認された。この問題は、AIショッピングエージェントがShopifyのストアから正確な商品情報を取得する際の障害となる可能性があり、特にAIによる自動販売やマーケティングツールの信頼性に影響を及ぼしている。また、この問題はShopifyのドキュメンテーションと実際のAPI動作との乖離を示しており、開発者やストアオーナーにとって重要な課題となっている。

## 共通して確認できる点

Shopifyのagent-commerceカテゴリフィルタが正しく機能していないことが確認されています。2026年9月2日に実施されたテストでは、10,099の知られているストアからランダムに選ばれた200店を対象に、5回の同じリクエストを送信しました。それぞれのリクエストでは、不可能なカテゴリ、有効なカテゴリ、価格フィルタの3種類のフィルタを組み合わせて送信し、結果を比較しました。その結果、190店のうち186店ではフィルタが無視され、未フィルタの結果が返ってきました。また、4店ではどのフィルタも無視され、結果が返ってきませんでした。カテゴリデータは商品自体に存在しているにもかかわらず、フィルタがそれを使用していないことが判明しました。価格.maxフィルタを用いた制御により、テストが誤配置であるか、カテゴリフィルタの失敗であるかを区別しました。150店では価格.maxフィルタが正しく動作しましたが、カテゴリフィルタはすべて無視されました。この問題は、Shopifyのドキュメントで記載されているagent-commerceの機能と、実際の運用でのギャップを明らかにしています。AIショッピングエージェントがShopifyのUCPを用いて商品検索を行う際、このカテゴリフィルタの問題は重大な課題となっています。

## 深掘り調査で得られた知見

Shopifyのagent-commerceカテゴリフィルタが意図通りに機能していないことが、2026年9月に実施された調査で確認されました。この調査では、10,099のShopifyストアから選定された200店を対象に、5回のテストが行われました。各テストでは、10製品をリクエストし、カテゴリフィルタや価格フィルタを組み合わせて検索を行いました。結果として、190店が応答し、そのうち186店ではフィルタが無視され、結果が未絞り出されたまま返ってきました。4店では、フィルタをかけた場合でも結果が返ってきませんでした。カテゴリデータは製品ごとに存在しているものの、フィルタがそれを使用していないことが判明しました。価格フィルタの最大値を変更した場合、結果が変化することを確認することで、カテゴリフィルタの無視が明確に証明されました。この問題は、AIショッピングアーキテクチャがShopifyのUCP（Universal Commerce Protocol）を活用して製品検索を行う際の重大な制限として浮き彫りとなりました。また、調査では、カテゴリフィルタの実装が不完全であることが指摘され、これはAIによる自動化されたマーケティングや販売活動において大きな影響を及ぼす可能性があります。

## 不確実な点・追加確認が必要な点

Shopifyのagent-commerceカテゴリフィルタが機能していないという問題については、複数の記事で検証が行われています。記事1と記事2では、2026年9月に実施されたテストにおいて、190店舗を対象にフィルタの動作を確認した結果、カテゴリフィルタが無視されていることが明らかになりました。ただし、記事1では、価格フィルタ（price.max）が正しく動作した一方で、カテゴリフィルタはすべての店舗で無視されていると報告されています。一方で、記事2では、フィルタの送信方法が誤っていた可能性があり、その結果としてカテゴリフィルタが機能していないと誤解されていた可能性があると指摘されています。このため、カテゴリフィルタが完全に無視されているかどうかは、テストの実施方法やフィルタの送信仕様に依存している可能性があります。また、記事1では、190店舗のうち186店舗がフィルタを無視し、4店舗は結果を返さなかったとされていますが、その理由や具体的な動作の違いについては明確ではありません。さらに、記事3や記事4、記事5の内容は、Shopifyの移行サービスや商品情報のスクレイピングツールについて述べており、カテゴリフィルタの問題とは直接的な関係がありません。したがって、カテゴリフィルタの問題に関する情報は、記事1と記事2に限定され、他の記事との整合性や追加確認が必要な点が存在しています。
