# CambioとAgentic Walletsの違いと用途の違い

## 結論

CambioとAgentic Walletsは、それぞれ異なる信頼モデルとユーザーのニーズに対応するための技術として設計されており、競合ではなく補完的な存在として機能している。Cambioはユーザーのウォレットを直接操作せず、自然言語の意図を解析してデターミニスティックな実行エンジンに変換する一方、Agentic WalletsはAIエージェントをユーザーのウォレット内に配置し、資産の管理やDeFi操作を自動化するインフラを提供している。この違いは、2026年の技術動向において、ユーザーの信頼度や使用目的に応じてそれぞれの解決策が最適であることを示している。

## テーマ概要

2026年現在、暗号通貨業界では「Cambio」と「Agentic Wallets」がそれぞれ異なる問題解決を目指して注目されている。Cambioは、ユーザーのウォレットを直接操作せず、自然言語の意図を解析してデターミニスティックな実行エンジンに変換するコンバーチョナル・スワップ・コンポーザーとして位置付けられている。一方、Agentic Walletsは、AIエージェントをユーザーのウォレット内に配置し、資産の管理や取引、DeFiポジションの再バランスを自動化するインフラを提供している。この2つのアプローチは、それぞれ異なる信頼モデルやユーザーニーズに対応しており、競合ではなく補完的な存在として機能している。特に、Stripe Machine PaymentsやCoinbase Agentic Walletsの登場により、マシン間支払いのためのインフラが整い、AIエージェントの実用性が高まっている。また、PonsやRobinhood Chainのプラットフォームが提供するトークン発行・トレーディング機能も、この分野の進化を加速している。これらの技術は、ユーザーの信頼モデルに応じて使い分けることが求められ、今後の暗号通貨の利用シーンにおいて重要な役割を果たしつつある。

## 共通して確認できる点

CambioとAgentic Walletsは、それぞれ異なる問題解決に特化したアプローチを取っている。Cambioは、ユーザーのウォレットを直接触れないことで、自然言語の意図を解析し、デターミニスティックな実行エンジンに変換するコンバーチョナル・スワップ・コンポーザーとして位置付けられている。一方、Agentic Walletsは、AIエージェントをユーザーのウォレット内に配置し、資産の保持、取引、コンピュートの支払い、DeFiポジションの再バランスを自動化するインフラを提供している。これらの技術は、2026年に主流となり、Bankr、deBridgeのMCPサーバー、Brian、Coinbase Smart Walletなどの製品が代表例として挙げられる。Cambioは、AIエージェントをコンポーザー内で動作させ、ユーザーのウォレットを非関与に保つことで、信頼モデルに応じて使い分けるべきであるとされている。一方、Agentic Walletsは、セッションキーを用いて制限されたスコープでトランザクションを実行し、ユーザーのウォレットに直接アクセスしない仕組みを採用している。また、Stripe Machine Paymentsは、HTTPレイヤーでのマシン間トランザクションのための標準化された支払いプロトコルを提供し、x402プロトコルを通じて支払い意図を標準化している。Coinbase Agentic Walletsは、AIエージェントが資産を保持し、取引、コンピュートの支払い、DeFiポジションの再バランスを自動的に実行できるようにするためのインフラを提供しており、x402プロトコルで動作している。これらの技術は、異なる信頼モデルに応じてそれぞれの用途に適している。

## 記事ごとの差分・視点の違い

記事「Cambio vs. Agentic Wallets: Different Problems, Different Solutions」では、Cambioとアグェンティックウォレット（Bankr、deBridgeのMCPサーバー、Brian、Coinbase Smart Walletなど）が解決すべき問題や信頼モデルの違いに焦点を当てており、それぞれが異なるユーザーニーズに対応するアプローチを採用していると説明している。Cambioはユーザーのウォレットを直接触らず、自然言語の意図を解析してデターミニスティックな実行エンジンに変換するコンバーチョナル・スワップ・コンポーザーとして位置付けられている一方、アグェンティックウォレットはユーザーのウォレット内にAIエージェントを配置し、制限されたスコープでトランザクションを実行する仕組みを提供している。  
記事「Stripe Machine Payments, Coinbase Agentic Wallets, and... — ATXP」では、Stripe Machine PaymentsとCoinbase Agentic Walletsがそれぞれマシン間支払いのためのインフラを提供しており、異なるアプローチを取っている点を強調している。Stripe Machine PaymentsはHTTPレイヤーでのマシン間トランザクションを標準化し、x402プロトコルを通じて支払い意図を標準化しているのに対し、Coinbase Agentic WalletsはAIエージェントが資産を保持し、取引やDeFiポジションの再バランスを自動化するためのインフラを提供している。  
記事「Building a Pons Copy-Trading System on Robinhood Chain」では、PonsプラットフォームとRobinhood Chainの関係性を解説し、トークンの発行と取引の仕組みを説明している。特に、Ponsはトークンの発行とトレーディングを可能にするプラットフォームとして位置付けられており、そのインフラはTypeScript SDKとイベントインデックスングレイヤーを活用して構築されている。  
記事「Oxa · Launch on Pons. Pair a penny stock.」では、Ponsプラットフォーム上でトークンを発行し、ペンニーストックとペアリングする仕組みを紹介している。Pons V2の曲線に基づいてトークンが開始され、ペアリングはボードから選ぶ名前で行われるという仕組みが説明されている。  
記事「Building a Real-Time Token Scanner on Robinhood Chain」では、Robinhood Chain上でリアルタイムでトークン活動を監視するシステムの構築を目指しており、Ponsに関連するトークン活動の監視が中心となる。このシステムは、トークンの動きを追跡し、トレーディングの分析を支援する目的で設計されている。

## 深掘り調査で得られた知見

CambioとAgentic Walletsは、それぞれ異なる課題を解決するために設計されており、ユーザーの信頼モデルに応じて使い分けるべきである。Cambioは、ユーザーのウォレットを完全に非関与にして、自然言語の意図を解析し、デターミニスティックな実行エンジンに変換するコンバーチョナル・スワップ・コンポーザーとして位置付けられている。一方、Agentic Walletsは、AIエージェントが資産を保持し、取引、コンピュートの支払い、DeFiポジションの再バランスを自動的に実行できるようにするインフラを提供している。例えば、Coinbase Agentic Walletsは、x402プロトコルを通じて支払い意図を標準化し、AIエージェントがユーザーの資産を管理するための共有バランス体験を実現している。また、Stripe Machine Paymentsは、HTTPレイヤーでのマシン間トランザクションのための標準化された支払いプロトコルを提供し、リクエストレベルでの検証や安定した決済セマンティクスを備えている。これらの技術は、2026年に主流となり、AIエージェントをユーザーのウォレット内に配置するアプローチが広く採用された。一方で、Cambioは、ユーザーのウォレットを触れないアプローチを取るため、コンポーザー内でAIエージェントを動作させている。このような違いは、ユーザーの信頼モデルや使用目的に応じて、それぞれの解決策が最適であることを示している。
