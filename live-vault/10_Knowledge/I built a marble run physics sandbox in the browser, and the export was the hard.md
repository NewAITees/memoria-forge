# ブラウザで動くマーブルランシミュレーションの技術的課題

## 結論

ブラウザ上で動作するマーブルランの物理シミュレーションツール「marble run physics sandbox」は、ユーザーが傾斜台、壁、ピン、スピナー、箱、ボールなどを配置し、リアルな剛体シミュレーションを実行できるクライアントサイドのアプリケーションである。このプロジェクトでは、動画のエクスポートプロセスが技術的に困難であり、WebGLキャンバスのスクリーンキャプチャではなく、オフスクリーンでの再レンダリングと動画エンコーダーへの直接出力により、30fpsで9:16の垂直動画を生成している。この方法により、シミュレーションの再現性を確保し、音声も視覚的フレームに同期して生成されている。

## テーマ概要

ブラウザ上で動作するマーブルランの物理シミュレーションツール「marble run physics sandbox」が注目を集めている。このツールは、ユーザーが傾斜台、壁、ピン、スピナー、箱、ボールなどを配置し、リアルな剛体シミュレーションを実行できる。また、生成されたシミュレーションを9:16の垂直動画としてエクスポートできるが、これは標準的な画面キャプチャではなく、オフスクリーンで再レンダリングし、30fpsで動画エンコーダーにフレームを直接送るという独自の方法を採用している。エクスポートプロセスはシミュレーションの確定性を保つために、固定 timestep とアキュムレータを用いることで、異なるハードウェアでも同じ結果を再現可能にしている。このプロジェクトは、クライアントサイドでの実行に特化しており、サインアップやログイン、AIの利用は一切ない。この技術は、ブラウザベースの物理シミュレーションや動画生成の分野で、新たなアプローチとして注目されている。

## 共通して確認できる点

複数の記事で共通して確認できた事実として、ブラウザ上で動作するマーブルラン物理シミュレーションの開発が行われたことが挙げられる。このプロジェクトでは、ユーザーが傾斜板、壁、ピギング、スピンナー、箱、ボールなどを配置し、シミュレーションを実行できる。また、シミュレーション結果を9:16の垂直動画としてエクスポートする機能が実装されており、その過程で技術的な課題が生じた。動画の生成には、オフスクリーンでの再レンダリングと、フレームごとのエンコーダーへの出力が用いられている。また、シミュレーションの再現性を確保するため、決定的な時刻に基づいたステップ処理が採用されている。さらに、音声も視覚的なフレームに合わせて生成され、音声と動画の同期が保たれている。このプロジェクトは、ログインやアップロード、AIの使用が一切必要とせず、デスクトップブラウザでの動作を前提としている。

## 深掘り調査で得られた知見

深掘り調査により、ブラウザ上で動作するマーブルラン物理シミュレーションの開発プロセスや、その実装における技術的課題が明確に判明した。このプロジェクトでは、ユーザーが傾斜板、壁、ピギー、スピンナーや箱、ボールなどを配置し、リアルな剛体シミュレーションを実行できる環境が構築されている。特に、シミュレーションの結果を動画形式でエクスポートするプロセスが技術的に困難だったことが強調されている。動画の生成には、WebGLキャンバスのスクリーンキャプチャではなく、オフスクリーンでの再レンダリングを採用し、1080x1920解像度で30fpsで動画エンコーダーにフレームを送信している。これにより、同じレベル設定で常に同じ動画が生成されるようにしている。音声も、衝突が発生するフレームにクリック音を生成して、視覚と完全に同期させている。また、固定 timestep と累積値を用いることで、異なるハードウェア環境でもシミュレーションの挙動が一貫性を保つように設計されている。ボールの衝突処理では、サブステップインテグレーションを採用し、薄いピギーを通過する_tunneling_現象を防いでいる。材質ごとの反発係数や摩擦係数を設定することで、現実的な物理的な挙動を再現している。また、照明の取り扱いも重要な要素とされており、単一の方向光とソフトな補助光、壁の微妙なテクスチャを組み合わせることで、3Dの魅力を引き出すことが求められている。このプロジェクトは、ブラウザ上で動作し、サインインやアップロード、AIの使用を一切行わない完全なクライアントサイドの実装である。また、この技術的工夫は、ブラウザベースの物理シミュレーション開発において、エクスポートプロセスの信頼性と再現性を高めるための重要な参考となる。
