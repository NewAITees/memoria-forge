# AWS Certified Generative AI Developer – Professional (AIP-C01) 試験概要

## 結論

AWS Certified Generative AI Developer – Professional (AIP-C01) 試験は、生成型AIをビジネスアプリケーションや業務フローに統合する実務スキルを評価するプロフェッショナル向けの認定であり、AWSの基礎モデルを活用した設計・構築・運用の知識が中心です。試験は75問で構成され、180分の時間内で解答し、750点以上を合格基準としています。この認定は、GenAIを活用した実世界のソリューションを構築するエンジニアにとって、業界標準的なスキルの証明として注目されています。

## テーマ概要

AWS Certified Generative AI Developer – Professional (AIP-C01) は、生成型AI（GenAI）をビジネスアプリケーションや業務フローに統合する能力を評価するプロフェッショナル向けの認定試験です。この試験は、AWSの基礎モデル（Foundation Models）を活用して、実際の生産環境でのアプリケーション開発や運用に必要な技術的知識と実践スキルを検証します。試験内容は、ベクターストアやリトリーバル拡張生成（RAG）、セキュリティ、コスト最適化、監視・トラブルシューティングなど、GenAIアプリケーションの設計・構築・運用に必要な分野をカバーしており、モデル開発や高度な機械学習技術の実装は試験の範囲外です。この認定は、GenAIを活用した実世界のソリューションを構築するエンジニアにとって、業界標準的なスキルの証明として注目されています。2026年3月17日にベータ期間が終了し、現在は一般受験が可能となっています。

## 共通して確認できる点

AWS Certified Generative AI Developer – Professional (AIP-C01) は、生成型AI（GenAI）開発者としての実務経験を持つプロフェッショナルを認定する資格試験です。この試験は、AWSサービスを活用して、ファウンデーションモデル（FM）をアプリケーションやビジネスワークフローに統合する能力を検証します。試験は75問の問題で構成され、180分の時間内で解答する必要があります。合格基準は750点（スケール100〜1000）で、試験内容は5つの主要な分野に分類されています。そのうち、ファウンデーションモデルの統合、データ管理、コンプライアンスが最も重みが大きいです。試験では、リトリーバル拡張ジェネレーション（RAG）、ベクトルストア、アジェンティックシステム、コスト最適化、セキュリティなどの実践的な知識が求められます。モデル開発や高度な機械学習技術は試験の範囲外とされています。また、受験資格として、AWS上でプロダクション品質のアプリケーションを開発する経験2年以上と、生成型AIソリューションを実装する実務経験1年以上が求められます。AIP-C01は、GenAI機能をすでに実装している開発者向けのプロフェッショナルレベルの認定であり、採用担当者が認識する標準的な基準として位置付けられています。

## 深掘り調査で得られた知見

AWS Certified Generative AI Developer – Professional (AIP-C01) 試験は、生成型AI（GenAI）の実装に精通したプロフェッショナルを認定するための資格であり、AWSの基礎モデル（Foundation Models）をアプリケーションやビジネスフローに統合する能力を評価します。試験は75問で構成され、180分の時間内で解答する必要があります。合格基準は750点（スケール100〜1000）で、5つの内容領域が含まれており、そのうち最も重みが高いのは「Foundation Model Integration, Data Management, and Compliance」（31%）です。この分野では、ベクトルストア、Retrieval Augmented Generation（RAG）、知識ベース、セキュリティ、ガバナンスなどの技術が問われます。一方で、モデルの開発や高度な機械学習技術は試験の範囲外とされています。  

試験対象者は、AWSでのプロダクション環境でのアプリケーション開発経験が2年以上、かつ生成型AIソリューションの実装経験が1年以上あることが求められます。試験は実践的な知識を重視しており、設計、構築、セキュリティ、運用、トラブルシューティングなど、GenAIアプリケーションの全ライフサイクルをカバーします。また、ベータ期間は2026年3月17日に終了し、現在は通常の登録が開始されています。  

この試験は、GenAI技術をビジネスに導入する開発者向けのプロフェッショナル認定として位置付けられており、採用担当者からも認知度が高いとされています。試験内容は、AWS公式ガイドに基づいており、実際の業務環境での実装能力を評価するための設計となっています。
