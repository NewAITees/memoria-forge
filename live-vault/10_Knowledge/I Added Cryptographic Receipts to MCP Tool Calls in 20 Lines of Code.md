## 深掘り調査で得られた知見

MCP（Model Context Protocol）において、暗号化されたレシート（cryptographic receipts）の導入が注目されている。この技術は、MCPツール呼び出しの安全性と信頼性を高めるために、各呼び出しに署名付きの証明書を添付する手法である。このアプローチは、引数の改ざんや応答の変更、スキーマの変更、遅延トリガー攻撃などの不正を検出するための手段として機能する。実装には、Ed25519による署名とタイムスタンプの使用が含まれ、結果は構造化されたContentフィールドに添付される。これにより、任意のMCPクライアントがレシートを検証できるようになる。  

この技術は、`ccs-mcp-server`ライブラリを通じて実装され、IETFのInternet-DraftであるCorrectover Conformance Shape（CCS）に準拠している。`ccs-verifier`パッケージを使用することで、Node.jsやPythonにおいてレシートの検証が可能となる。また、レシートは追加不可のアペンドオンリーストアに保存されるため、改ざんや削除が不可能である。  

レシートの生成には、認証プロキシを経由する方法が採用される。プロキシは、出力API呼び出しを中継し、正確なリクエストとレスポンスのバイトをキャプチャし、独立した証明書を返す。これにより、誰もが独立して検証可能な証拠が得られる。このアプローチは、AIエージェントの行動を記録し、信頼性の高いアカウントを提供するための重要な手段として位置付けられている。  

MCPの進化として、2026年7月28日に発表された新規仕様では、ステートフルな通信からステートレスな通信へと移行している。この変更により、セッションIDやハンドシェークが廃止され、各リクエストが自立して処理されるようになっている。この変更により、MCPサーバーの実装は再設計が必要となり、特にPython SDKにおいては大きなリファクタリングが求められている。  

このような背景の中で、暗号化レシートの導入は、ステートレスなMCP環境でも信頼性を確保するための重要な技術として注目されている。特に、AIエージェントの行動を透明化し、その行動が信頼できる形で記録されることが求められる現代のシステムにおいて、この技術は重要な役割を果たしている。
