# クラウドシェルでのファイル管理3つの方法

## 結論

AWS CloudShellは、AWS Management Consoleから起動可能なブラウザベースのシェル環境であり、ファイル管理やAWSリソースの操作が可能。ホームディレクトリには各AWSリージョンごとに1GBの永続ストレージが提供され、セッション間でもデータが保持される。一方、SelfCmdやAI-SSH-Proなどのツールは、SSH接続管理やAIによるエラー診断、ファイル操作を含む柔軟な機能を提供し、クラウド環境でのファイル管理の効率化とセキュリティ向上に貢献している。

SelfCmdは、SSH/シリアル接続管理、コマンドライブラリ、AIによるエラー診断を統合したツールで、ローカルマシンにのみ実行し、クラウドにデータを送信しない。ファイル管理やSFTP転送、リモートファイル構造の閲覧、リソース監視機能を備えている。コマンドライブラリを活用して、頻繁に使用するコマンドを再利用可能なボタンに変換し、AIによるエラー診断をサポートしている。この記事は、SelfCmdの機能と、SSH接続管理、コマンド実行、AI診断の統合について詳しく説明している。

AI-SSH-Proは、ローカルで動作するマルチセッションSSHクライアントで、AIによるコマンド提案と実行制御（Suggest only、Confirm before run、Auto run）を提供。UIは英語と中国語に対応し、セキュリティ機能として高リスクコマンドの承認、読み取り専用ホスト、サンドボックス環境を備えている。この記事は、AI-SSH-Proの主な機能と、AIオペレーションズアシスタントの動作仕様について説明している。

## 深掘り調査で得られた知見

AWS CloudShellでは、ファイル管理にはホームディレクトリ内に1GBの永続ストレージが提供され、セッション間でもデータが保持されます。ファイル編集にはvimやnanoなどのテキストエディタが利用可能で、それぞれの特徴を活かした操作が可能です。また、Bash、PowerShell、Z shellの切り替えが可能で、柔軟なシェル操作が可能です。セッションは20〜30分の不活動後にタイムアウトし、リソースが再利用されます。VPC環境では、ホームディレクトリのデータが削除されるが、それ以外の環境では永続的なストレージが提供されます。CloudShellは、リージョンや環境によって、セッションのタイムアウト時間や永続ストレージの提供条件が異なる可能性があります。

一方、SelfCmdは、SSH/シリアル接続管理、再利用可能なコマンドライブラリ（Cmd Lib）、クロスプラットフォームのローカルおよびリモートコマンド実行、AI駆動の自動エラー診断を1つのインターフェースで統合しています。SelfCmdは、Windows、macOS、Linux向けのネイティブビルドアプリケーションであり、ローカルマシンにのみ実行し、クラウドにデータを送信しません。SelfCmdは、接続管理機能を備えており、接続名、IPアドレス、ポート、ユーザー名、認証方法（パスワードまたはSSHキー）、ジャンプホスト（バストンホスト）の使用、グループとタグの設定、AIエージェントの実行権限などのパラメータを設定できます。SelfCmdは、コマンドライブラリを活用して、頻繁に使用するシェルコマンドや診断スクリプトを再利用可能なボタンに変換します。SelfCmdは、ローカルおよびリモートでコマンドを実行し、繰り返しの実行（リピートモード）やスケジュール実行をサポートします。SelfCmdは、コマンド実行が失敗した場合や非ゼロのステータスコードを返した場合、AIによるエラー診断機能を活用して、原因を分析し、解決策を提示します。SelfCmdは、SSH接続管理に加えて、ファイル管理、MD5チェックサム生成、SFTPによるファイル転送、直感的なインターフェースでリモートファイル構造を閲覧する機能を備えています。SelfCmdは、リモートサーバーのリソース監視（CPU、メモリ、ディスク使用量、ディスクI/O、ネットワーク帯域幅、SSD/NVMeディスク寿命（SMARTウェア）など）をサポートします。SelfCmdは、カスタムコマンドのパラメータ化、複数のコマンドやSFTP転送をワークフローとして連鎖し、繰り返し実行可能なプロセスを構築します。SelfCmdは、プロのライセンスを取得することで、完全にオフラインで動作し、クラウドにデータを送信しません。

AI-SSH-Proは、ローカルで動作するマルチセッションSSHデスクトップクライアントであり、AIオペレーショナルアシスタントがコマンドを提案し、ユーザーが実行方法を決定できます（提案のみ、実行前確認、自動実行）。UIは英語と中国語の両方で利用でき、設定メニューで言語を切り替えることができます。AI-SSH-Proは、OPS/SREエンジニア、バックエンド開発者、小規模チームリーダー、Xshell/FinalShellのユーザーなどに設計されており、AIアシスタントはターミナルインターフェースに統合されています。コマンドは読み取り、書き込み、高リスク、インタラクティブに分類され、高リスクコマンドは明示的なユーザー承認が必要です。セキュリティ機能には、ホストごとの安全ポリシー、読み取り専用ホスト、および自動実行モードのためのサンドボックス環境が含まれていますが、OSレベルのサンドボックスではありません。プライベートキー、SSHパスワード、LLM APIキーはローカルマシンに保存され、リポジトリに送信されません。AI-SSH-ProのGitHubリポジトリは、ソースコードはMITライセンスの下で公開されています。dev.toの記事は、AI-SSH-Proアプリケーションの特徴と動作について詳細に説明しており、GitHubリポジトリはアプリケーションのアーキテクチャ、機能、実装についての技術的な詳細を提供しています。Microsoft Storeのリストでは、AI-SSH-Proを「ユーザーが平易な英語でニーズを説明し、正確なコマンドを生成できるようにするリモートサーバー管理ツール」と説明しています。
