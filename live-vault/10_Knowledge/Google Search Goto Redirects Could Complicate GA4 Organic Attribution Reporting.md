# Google Search Goto Redirects が GA4 有機アトリビューションに与える影響

## 結論

Google Search が検索結果のリンクを `google.com/goto?url=...` という中間 URL を経由するリダイレクト仕組みを導入したことで、GA4 の有機的 attributing レポートの正確性に影響を与える可能性がある。この変更は 2026 年 6 月から 8 月にかけて段階的に導入され、SEOツールやスクラッピングツールの動作に新たな課題をもたらしている。リダイレクトが Google のドメイン内で行われるため、GA4 は通常通り有機トラフィックを報告するが、最終的な宛先 URL の取得が困難となり、アトリビューションの精度が低下する懸念が生じている。

## テーマ概要

Google Search が検索結果のリンクを直接的な URL ではなく、`google.com/goto?url=...` という中間 URL を経由する形でリダイレクトする仕組みを導入したことで、GA4 などのアナリティクスツールにおける有機的 attributing のレポートが複雑化している。この変更は、2026年6月から8月にかけて段階的に導入され、検索結果のリンクがユーザーの最終到達先を直接示さなくなった。これにより、SEOツールやスクレイピングツールが以前のように直接的な URL を取得できず、データの正確性や分析の精度に影響を与える可能性がある。特に、GA4 はリダイレクト前の Google ドメインでのトラフィックを記録するため、ユーザーが最終的に訪れるページのデータは通常通り報告されるが、有機的 attributing の正確性が低下する懸念が生じている。この変更は、Google が技術的な対策を講じるためのものであり、SEO業界や分析ツールの開発者にとって新たな課題を生んでいる。

## 共通して確認できる点

Google Search では、検索結果のリンクが以前のように直接の宛先 URL ではなく、中間 URL（google.com/goto?url=...）を通じてリダイレクトする仕組みが導入された。この変更は、2026年6月下旬から8月下旬にかけて段階的に導入され、8月26日に Google が Search Engine Roundtable および Search Engine Land に対して公式に確認を出している。この変更により、検索結果のリンクは Google のドメインを経由する形となり、第三者ツールや SERP スクレイピングツールが直接宛先 URL を取得できなくなった。GA4 や Search Console などのアナリティクスツールは、リダイレクトが Google のドメイン内で行われるため、有機的トラフィックの報告は通常通り行われるが、リダイレクト先の URL はクライアントサイドでは取得できず、サーバーサイドでのリダイレクトを経て最終的な宛先に到達する。この変更は、SEO およびアナリティクスのデータ取得に影響を与える可能性があるが、Google は具体的な技術的背景や目的を明示していない。また、ログイン状態によってリダイレクトの振る舞いが異なるという報告もあり、完全な一貫性は確認されていない。
